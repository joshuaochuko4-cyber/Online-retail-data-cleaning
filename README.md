# Online-retail-data-cleaning
# 🛒 Online Retail Data Cleaning & Exploratory Data Analysis

## 📌 Project Overview

This project focuses on cleaning and analyzing an online retail dataset to uncover sales patterns, customer purchasing behavior, and revenue trends. The analysis was carried out as part of the **AnalystLab Africa Data Analytics Internship Program (Batch B, June–August 2026)**.

The primary objective was to transform raw transactional data into a structured, analysis-ready dataset and generate meaningful business insights through Exploratory Data Analysis (EDA).

---

## 🎯 Objectives

- Understand the structure and quality of the dataset.

- Identify and handle missing values.

- Detect and remove duplicate records.

- Standardize data formats and validate records.

- Explore trends and patterns within the data.

- Generate actionable business insights through visualization.

---

## 📂 Dataset Description

The dataset contains transactional records from an online retail business, including:

- Invoice numbers

- Product descriptions

- Quantities purchased

- Invoice dates

- Unit prices

- Customer IDs

- Countries of purchase

---

## 🛠️ Tools & Technologies

- Python

- Pandas

- NumPy

- Matplotlib

- Jupyter Notebook

---

## 🔧 Data Cleaning Process

The following cleaning steps were performed:

- Handled missing values appropriately.

- Removed duplicate records.

- Standardized column names.

- Converted date fields to datetime format.

- Validated data by identifying and removing invalid entries (e.g., negative quantities and prices).

- Checked for outliers and anomalies.

---

## 📊 Exploratory Data Analysis (EDA)

The following analyses were conducted:

1. Top-selling products

2. Revenue generated by country

3. Monthly sales trends

4. Customer purchasing behavior

5. Revenue distribution analysis

---

## 📈 Visualizations

The project includes:

- Bar charts

- Line charts

- Histograms

- Box plots

These visualizations were used to communicate trends and support insights derived from the analysis.

---

## 💡 Key Insights

- A small number of products contributed significantly to overall sales volume.

- Certain countries generated the majority of total revenue.

- Sales exhibited noticeable fluctuations across different months.

- Customer spending behavior varied considerably.

- Proper data cleaning improved the reliability of analytical outcomes.
